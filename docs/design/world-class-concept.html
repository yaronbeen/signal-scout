New to Bright Data? Setup checklist
  1. Create an account with credits. Check pricing before searching.
  2. Enable Web Scraper API access. Required for creator collection on all five platforms. Setup guide ↗
  3. Create a working SERP API zone. Required for Instagram, LinkedIn and X. After connecting, select it in the search form. “Active” does not prove the zone works. Search zone guide ↗
  4. Optional: enable Web Unlocker. Only for separately billed website email scans. Website scan guide ↗
  5. Enter your key in the app, choose your search zone, topics, platforms and depth, then search.
After connecting & resuming work

Choose the search zone configured for working Google searches for Instagram, LinkedIn and X. Connecting checks account metadata without a paid search; it does not verify all permissions, credits, or zone health.

Collections can take several minutes. After refreshing, reconnect and resume existing snapshot jobs. Resume can start a separate paid profile-enrichment stage. Pausing or discarding references does not cancel provider jobs. Never repeat an uncertain submission automatically.
