# Clear Signal release notes

## A clearer research workspace

- Horizontal navigation, readable self-hosted Geist type, restrained Bright Data accents, and original sample illustrations.
- A split arrival/search composition transitions into a compact brief ribbon and evidence-led creator cards.
- Named mobile platform filters, visible Edit/New search actions, and responsive details/setup dialogs.
- Complete hosted visitor instructions plus separate copyable coding-agent and human local-installation handoffs.

## More trustworthy evidence

- Card previews show the evidence supporting their topic-match label.
- Native biographies remain profile evidence; captions/titles/post text supply authored-content evidence.
- TikTok publication dates are preserved; LinkedIn empty repost metadata no longer drops original authors.
- Profile collection state stays pending/partial/complete/unknown per creator through saving, reload, and CSV export.

## Reliable collection and recovery

- Successful discovery candidates display while bounded post collection runs.
- Confirmed terminal failures are distinguished from transient snapshot polling errors.
- A returned snapshot that cannot be persisted stays visible for manual preservation and stops later collection.
- Recovery remains usable with the composer hidden, including explicit zone choice.
- Metadata permissions, separate paid stages, key lifetime, tab-local job references, and uncertain-submission handling are explained in context.

## Verification boundaries

Automated acceptance covers contracts, recovery, desktop/mobile flows, responsive widths, untidy data, modal interaction, evidence, and setup. Current live verification separately identifies new calls, reused snapshots, direct known-post checks, fallback profiles, and unverified stages. Provider availability and influencer suitability are never guaranteed.
